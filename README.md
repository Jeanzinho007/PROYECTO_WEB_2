ATHLETIQ - Monitoreo Total en Vivo 🚀
ATHLETIQ es una landing page de alta fidelidad diseñada para una plataforma de tecnología deportiva y métricas en tiempo real. Este proyecto está enfocado en ofrecer una interfaz moderna, limpia y atractiva para deportistas y entrenadores.
🌟 Características de la Interfaz
Diseño Moderno (Dark Mode): Estética profesional basada en un esquema de colores oscuros con acentos en cian (#06B6D4), blanco y gris.
Sección Hero Impactante: Mensaje principal claro, etiquetas de tecnología y llamadas a la acción (CTAs) interactivas ("Saber más" y "Ver demo app").
Showcase de Producto: Sección dedicada al chaleco inteligente con visualización de biométricas y elementos gráficos interactivos.
Flujo de Proceso ("Cómo Funciona"): Tarjetas organizadas horizontalmente para explicar de forma sencilla el funcionamiento de la plataforma.
🛠️ Tecnologías y Herramientas
Figma: Diseño de interfaz de usuario (UI), wireframing y prototipado interactivo.
HTML / CSS / Tailwind CSS (según implementación) para el desarrollo web responsivo.
📂 Estructura del Proyecto
Header / Navegación: Menú superior fijo con enlaces rápidos a las secciones principales y botón de descarga.
Hero Section: Presentación de valor principal de la marca.
Sección Chaleco: Especificaciones de hardware y monitorización biométrica.
Cómo Funciona: Guía paso a paso del ecosistema ATHLETIQ.
Desarrollado con enfoque en la experiencia de usuario y rendimiento deportivo.
